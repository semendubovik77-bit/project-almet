# ӘЛМӘТ — фотопутеводитель по Альметьевску

Готовый адаптивный многостраничный сайт-заготовка для школьного проекта. В нём уже созданы:
- главная страница;
- 15 отдельных адресов объектов (`/places/obekt-01/` ... `/places/obekt-15/`);
- отдельный QR-код на каждой странице (он строится по фактическому адресу страницы);
- мобильная версия и оформление в стилистике твоей фотокниги: тёплый кремовый фон, приглушённые зелёные оттенки, крупная типографика и большие фотоблоки.

## Как заполнить объекты

Открой файл `places.json` в Блокноте или VS Code. Для каждого объекта измени:
- `title` — название;
- `address` — адрес;
- `category` — тип места;
- `description` — описание;
- `facts` — три интересных факта;
- `photo` — путь к фотографии, например `assets/park.jpg`.

Фотографии положи в папку `assets`. Если у объекта пока нет фотографии, будет показана аккуратная заглушка.

## Как проверить на компьютере

Самый простой вариант — загрузить папку на Vercel или GitHub Pages. Для локальной проверки можно открыть `index.html`, но браузер может ограничить загрузку JSON. Лучше запустить локальный сервер:
1. Установи Visual Studio Code и расширение Live Server.
2. Открой в VS Code эту папку.
3. Нажми правой кнопкой на `index.html` → **Open with Live Server**.

## Как опубликовать

### Vercel
1. Загрузи все файлы этой папки в новый GitHub-репозиторий.
2. На Vercel нажми **Add New → Project** и импортируй репозиторий.
3. Для обычного статического сайта оставь Framework Preset = Other, Build Command и Output Directory пустыми.
4. Нажми Deploy. Получишь публичную ссылку.

После публикации открой каждую страницу объекта. QR-код на ней будет вести на её полный публичный адрес. Сканируй код другим телефоном для проверки, прежде чем вставлять его в макет фотокниги.

## Важно про QR-коды
QR-код должен быть сгенерирован после публикации сайта, когда у каждой страницы уже есть постоянная ссылка. Если поменяешь домен, QR-коды в фотокниге придётся обновить. Для печати открой нужную страницу и нажми «Распечатать страницу» — QR-код попадёт в печатную версию.
